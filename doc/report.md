# Отчёт S3 (черновик недели 1). ТЗ v2.0, FIP-1.0

## 1. Постановка
Цепочка T -> eps_th -> sigma -> eps_pl + eps_tr -> остаточная форма -> допуски.
Сталь 45/AISI 1045; наплавка модельная 316L (уровень A — без геометрии слоя).
Объекты P01 (пластина, тракт), R01 (кольцо, овальность). Автономность;
данные только модельные (FIP-1.0) и открытые.
Вне объёма: ванна, течение, порошок, силы резания, водород, ползучесть.

Значения FIP 2.1. CE_IIW = 0.6283, Ms_Andrews = 321.9 C (scripts/km.py).

## 3. Постановка механики
Квазистатика: c = sqrt(E/rho) ~ 5170 м/с; 0.55/5170 ~ 1.1e-4 с против теплового
0.1–10 с -> отношение 1e3–1e5, инерцию отбрасываем.
eps = eps_el + eps_pl + alpha_sec(T)(T−Tref)I + beta*fM*I.
Tref основного металла 423.15 K (подогрев); слоя ~0.5–0.8 Tm.
alpha СЕКУЩИЙ — подтверждено исходником (results/a0_tables.md).
Отжиг Tcut = 1200 C. Зажим — главный источник овальности; плоскость симметрии
убивает нечётные гармоники -> для овальности нужно полное кольцо 360.
Оценки 3.4: dd = 0.66 мм; sigma 252/360/630 МПа; при dT = 800 К ~2900 МПа >> sigma_y;
kappa = 0.075 1/м, delta = 0.375 мм; dT для 70 мкм на D550 = 10.6 К; масса ~8.9 кг;
запас по припуску 0.8−0.5−0.2 = 0.10 мм.

### Объяснение расхождений >1% (обязательно по 8.1)
A2: сегрегированный решатель с термочленом grad(3K*alpha*T) не сходится к мягкой
изгибной моде: начальные невязки корректоров стоят ~2e-5 (Dx 2.16e-5 -> 9.5e-10
за 78 итераций, но внешние корректоры невязку не уменьшают), решение остаётся
почти стеснённым, sigma ~ E*alpha*max|T| ~ 119 МПа. Профиль T проверен корректным:
−46.875…+46.875, среднее 0.
A3/A4: связка planeStress yes + empty внутренне несамосогласована для
термонапряжений: eps_zz принудительно 0, а calculateStress считает sigma_zz по
3D-формуле -> фиктивные ~194 МПа при свободном расширении и занижение sigma_theta
~0.7x. Тонкий-3D со свободными торцами физически верен, но имеет свободную
поступательную z-моду -> PCG с relTol 0 падает (вырожденная матрица).
Вывод: ограничение стокового решателя уровня A, не ГУ и не сетка.
Мера: уровень B (solids4foam) либо solidEquilibriumDisplacementFoam;
вынесено в issues/question-01-solver-limitation.md.
Допущение: упругость «по построению» (стоковый решатель без пластичности,
условие sigma_y = 5000 МПа выполняется автоматически).
